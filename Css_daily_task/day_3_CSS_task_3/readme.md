# CSS Daily Task 03 - IndusInd Bank Credit Card Payment Form

## 📌 Description

Created and styled an IndusInd Bank Credit Card Payment Form using HTML5 and CSS3.

This project focuses on designing a modern banking payment interface with card selection, form controls, and responsive layout using CSS.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 CSS Concepts Covered

- External CSS
- CSS Selectors
- Background Color
- Text Styling
- Borders
- Border Radius
- Margin and Padding
- Flexbox
- Form Styling
- Input Styling
- Image Styling
- Button Styling
- Box Model

## ✨ Features

- Credit Card Payment Form
- Card Type Selection
- Visa, Mastercard and RuPay Cards
- Credit Card Number Input
- Confirm Card Number
- Email Input
- Mobile Number Input
- Payment Amount Input
- Bank Account Selection
- Submit Button
- Clean Banking User Interface
