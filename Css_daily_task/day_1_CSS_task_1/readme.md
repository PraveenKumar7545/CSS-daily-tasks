# CSS Daily Task 01 - College Application Form

## 📌 Description

Created and styled a College Application Form using HTML5 and CSS3.

This project is a continuation of my HTML form practice. I used CSS to improve the layout, spacing, alignment, and overall appearance of the form.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 CSS Concepts Covered

- External CSS
- CSS Selectors
- ID Selectors
- Class Selectors
- Form Styling
- Input Styling
- Label Styling
- Spacing and Alignment
- Buttons Styling
- Layout Design
- CSS Box Model

## ✨ Features

- Student personal information form
- First name and last name fields
- Email and password fields
- Phone number input
- Gender selection
- Multiple skills selection
- Department dropdown
- Date of birth selection
- Time selection
- Favorite color selection
- File upload option
- Register button
- Reset button
