# CSS Daily Task 02 - SBI Fund Transfer Form

## 📌 Description

Created and styled an SBI NEFT Fund Transfer Form using HTML5 and CSS3.

This project focuses on designing a banking transaction form with tables, form controls, and a clean user interface using CSS.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 CSS Concepts Covered

- External CSS
- CSS Selectors
- Background Color
- Borders
- Border Radius
- Margin and Padding
- Width
- Text Alignment
- Table Styling
- Form Styling
- Input Styling
- Button Styling
- Box Model

## ✨ Features

- SBI NEFT Transfer Form
- Account Selection Table
- Beneficiary Selection Table
- Amount Input
- Purpose Dropdown
- Payment Option Selection
- Submit Button
- Cancel Button
- Clean Banking Form Layout
