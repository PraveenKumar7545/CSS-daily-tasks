# CSS Daily Task 05 - NAB Personal Banking Landing Page

## 📌 Description

Created and styled a NAB Personal Banking landing page using HTML5 and CSS3.

This project focuses on designing a modern banking website layout with navigation, hero banner, service sections, promotional cards, and footer using CSS.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 CSS Concepts Covered

- External CSS
- CSS Selectors
- Flexbox Layout
- Background Images
- Background Colors
- Borders
- Border Radius
- Margin and Padding
- Width and Height
- Text Styling
- Image Styling
- Button Styling
- Box Model
- Layout Design

## ✨ Features

- Navigation Bar
- Hero Banner Section
- Popular Banking Solutions
- Home Loan Promotion
- Savings Promotion
- Banking Service Cards
- Quick Links Section
- Policies & Terms
- Social Media Links
- Footer Layout
- Responsive Flexbox Layout
- Custom Buttons and Cards
